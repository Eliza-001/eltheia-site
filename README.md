# eltheia.com

Static company site for Eltheia Inc. Plain HTML and one stylesheet, no build step. Hosted on GitHub Pages from `main`; `CNAME` holds the domain. Pages serves `/privacy` for `privacy.html`, so links stay clean.

The app-specific privacy policy and terms live in each app; these pages link to them. When Eltheon (the reader) moves to its own domain, update the links in `privacy.html` and `terms.html`.
