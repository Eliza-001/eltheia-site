# eltheia.com

Static company site for Eltheia Inc. Plain HTML and one stylesheet, no build step. Deployed on Vercel; `vercel.json` gives clean URLs (`/privacy`, `/terms`, `/support`).

The app-specific privacy policy and terms live in each app; these pages link to them. When the Reader moves to its own name or domain, update the links in `privacy.html` and `terms.html`.
